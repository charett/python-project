# Приложение "Weather Diary" (Дневник погоды)

**Автор:** [charett]

## Описание
Программа позволяет записывать данные о погоде (дату, температуру, описание и осадки). 
Данные автоматически сохраняются в формат JSON. Реализована фильтрация по дате и температуре.

## Как запустить
1. Установите Python 3.x.
2. Скачайте файл `main.py`.
3. Запустите его командой:
    bash
     python main.py
